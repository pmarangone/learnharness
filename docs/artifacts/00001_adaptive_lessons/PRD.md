# Problem and outcome

The teacher planned a Rivet lesson but presented five linked concepts together. After the learner requested one concept and question at a time, the teacher paused for another "next". The existing plan graph contains coarse topics and infers its position from quiz calls, so it cannot represent an ordered sequence within a topic or an interruption and return point.

Deliver an outline for the current lesson that the agent can maintain and resume, plus a way to add a deeper branch to an existing node. Respect the learner's current pacing and do not confuse visited material with mastery.

Existing sessions, messages, pending questions, plan graphs, bookmarks, and shared data remain usable. Do not claim compatibility with the original installed app until tested. Separate lesson metadata must not bump the existing chat-record version.
