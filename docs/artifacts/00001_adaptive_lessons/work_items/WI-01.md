# WI-01: Lesson steps

Status: LANDED (2026-10-28; commit containing this card)

Data shape: a session-scoped outline containing the problem, ordered teaching steps, their current position, and grounded source references or open questions. The position is a presentation state, not a mastery verdict. Existing sessions may have no outline.

Scope: adapt the teacher's planning and teaching instructions; give it a validated way to save and read the outline; preserve it on restart and compaction; continue from an answered question according to the learner's latest pacing request. Respect a request to pause, a follow-up, or an unresolved answer.

Files: `src/agent/prompts/teacher/{05-method,10-planning,20-teaching,28-predictions}.md`, `src/agent/tools/{lesson,plan}.ts`, `src/agent/{teacher-agent,tools}.ts`, `src/core/{lesson,contracts/chat}.ts`, `src/server/{lesson,chat-handler,chats,compaction}.ts`, `src/store/lesson.ts`, and focused tests.

Acceptance:
- A lesson states the problem and its outline, then presents one meaningful step and its question, rather than revealing all steps in the same response.
- After an answer the agent can explain it and move to the next step, unless clarification or the learner's requested pacing calls for staying or pausing.
- The outline and position survive reload and compaction; facts, sources, and uncertainties remain distinct.
- Existing sessions and pending questions still open and continue without bulk migration, deleting content, or bumping the shared chat schema.
- The original app remains readable and its changes cannot silently misdirect a resumed lesson; test against copies, not the learner's live data.
- Existing map and progress behavior remain truthful; a position does not assert understanding.
- Run focused behavioral tests and a realistic session entry-point check.
