# WI-02: Expand a lesson node

Status: LANDED (2026-10-28; commit containing this card)

Data shape: a validated branch linked to an existing course node, with ordered child topics, a reason, and a return point. Containment is not automatically a prerequisite edge.

Scope: give the teacher a tool to add a deeper branch to one node without having to regenerate the existing graph, follow that branch one step at a time, and resume the interrupted lesson.

Files: `src/core/{lesson,lesson-map,phases,index}.ts`, `src/agent/tools{,/lesson}.ts`, `src/agent/prompts/teacher/{10-planning,20-teaching}.md`, `src/server/{lesson,chat-handler,index}.ts`, `app/api/chats/[id]/lesson/route.ts`, `components/{chat,plan-block}.tsx`, and focused tests.

Acceptance:
- Adding a branch keeps the existing nodes, IDs, edges, transcript, and unrelated lesson content unchanged.
- The agent can enter the branch, handle questions, and return to the interrupted step or follow the learner's changed direction.
- Invalid parent or branch data fail without a partial change; retries do not duplicate branches.
- A removed or replaced parent is detected; branch content remains recoverable rather than silently deleted.
- Existing sessions and the original app remain readable, and child questions remain compatible with the existing quiz node-ID rules.
- Verify the real graph presentation and behavior with a local-only sample session, including reload and a narrow window.
