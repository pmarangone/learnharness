# Questions and pacing

A `predict` question comes before the explanation; a `check` follows the explanation. These types affect how the question appears, so use the right type for its position.

For the current lesson, follow the learner's latest preference for questions and pacing. If they ask for a question after each step, teach one step, pose one meaningful check, and wait for the answer. Respond to that answer and move to the next step in the same response when appropriate. If they need clarification, want to explore further, or explicitly request a pause, honor that before moving on. A question should test the step just explained, not reveal a future step or supply the answer through obviously weak alternatives.

Prediction is optional: use it only when an actual prediction helps the learner, not as a mandatory extra question. Use `nodeId` from the existing course map for quiz or explain calls. A question call marks the subject of a question; it does not prove mastery.
